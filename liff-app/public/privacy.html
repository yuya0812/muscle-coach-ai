プライバシーポリシー

2026年5月7日 制定 / 施行
マッスルコーチAI（以下「本サービス」）の運営者（以下「当社」）は、利用者から取得する個人情報について、個人情報保護法および関連法令を遵守し、以下のとおり取り扱います。

1. 取得する情報

本サービスでは、サービス提供のため以下の情報を取得します。

  • LINEプラットフォームから提供される情報: LINEユーザーID、表示名、プロフィール画像URL
  • 利用者が本サービス内で入力する情報: トレーナー名、目標、レベル、利用可能器具、頻度、年代、性別、身長、体重、体脂肪率、活動レベル、目標体重、目標体脂肪率、重点部位
  • ワークアウト記録: 種目名、重量、回数、セット数、日付
  • 通知・自動送信設定
  • AI会話の内容: AIトレーナーとのチャットメッセージ
  • 課金関連情報: Stripeから提供される顧客ID、サブスクリプションステータス、決済日時。カード番号は当社では保持せず、Stripeが直接処理します。
  • 利用ログ: アクセス日時、利用機能、エラーログ

2. 利用目的

取得した情報は以下の目的で利用します。

  1. 本サービスの提供および運営
  2. AIによるパーソナライズされたアドバイス・メニューの生成
  3. サブスクリプションの管理および課金処理
  4. 利用状況の分析および本サービスの改善
  5. お問い合わせへの対応
  6. 重要なお知らせの通知
  7. 不正利用の検知および防止

3. 第三者提供

当社は、以下の場合を除き、利用者の個人情報を第三者に提供しません。

  1. 利用者の同意がある場合
  2. 法令に基づき開示が必要な場合
  3. 人の生命、身体または財産の保護のために必要がある場合で、本人の同意を得ることが困難である場合
  4. 業務委託先への提供（下記4参照）

4. 業務委託先

当社は、以下のサービス提供者に対し、本サービス提供のために必要な範囲で情報を提供しています。これらの委託先は、それぞれのプライバシーポリシーに基づいて情報を取り扱います。

委託先 委託の目的 提供される情報
Google LLC

5. データの保管場所

利用者の個人情報は、Google Cloud Firestore（asia-northeast1 リージョン、東京）上に保管されます。

6. 保管期間

  1. アクティブな利用者のデータは、利用継続中保管されます。
  2. サブスクリプション解約後は、解約日から90日間保管した後、削除されます。
  3. 利用者が削除を申請した場合、原則として申請から30日以内に削除します。
  4. 法令上の保管義務がある情報については、当該義務期間中保管します。

7. 利用者の権利

利用者は、自己の個人情報について以下の権利を有します。

  1. 開示請求
  2. 訂正・追加・削除請求
  3. 利用停止または消去の請求
  4. 第三者への提供停止の請求

これらの請求は、後記のお問い合わせ窓口までご連絡ください。本人確認の上、速やかに対応します。

8. クッキーおよびLocalStorage

本サービスは、利用者の端末のLocalStorageを使用して以下の情報を保存します。これらの情報は、サービス提供および利便性向上のために使用されます。

  • オンボーディング完了状態
  • 操作チュートリアル（ツアー）の表示状態
  • LIFFのアクセストークン（LINE SDKによる管理）

9. AI処理に関する注意

利用者がAIトレーナーに送信したメッセージおよびトレーニング記録は、Anthropic, PBC のClaude APIを通じて処理されます。Anthropicは独自のプライバシーポリシーに基づき情報を取り扱います。AnthropicはAPI経由で送信された会話データをモデル訓練に使用しないことを明示しています（2026年5月時点）。詳細は Anthropicのプライバシーポリシー をご参照ください。

10. 安全管理措置

当社は、個人情報の漏洩、滅失または毀損を防ぐため、以下の措置を講じます。

  1. アクセス権限の制限（Cloud Functions経由のみ書き込み可）
  2. 通信の暗号化（HTTPS / TLS）
  3. Firebase Security Rulesによる直接アクセス禁止
  4. LIFFアクセストークン認証によるユーザー識別
  5. 業務委託先の選定および監督

11. プライバシーポリシーの変更

当社は、必要に応じて本プライバシーポリシーを変更することがあります。重要な変更がある場合は、本サービス内またはLINEメッセージによって利用者に通知します。
