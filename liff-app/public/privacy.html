プライバシーポリシー

2026年5月7日 制定 / 2026年5月12日 改訂
マッスルコーチAI（以下「本サービス」）の運営者（以下「当社」）は、利用者から取得する個人情報について、個人情報保護法および関連法令を遵守し、以下のとおり取り扱います。
カード情報について
クレジットカード番号・有効期限・セキュリティコード等の決済情報は、Stripe Inc.（PCI DSS 認定の決済代行業者）が直接処理し、当社のサーバーには一切保存されません。

1. 取得する情報

  • LINEプラットフォームから提供される情報: LINEユーザーID、表示名、プロフィール画像URL
  • 利用者が入力する情報: トレーナー名、年代、性別、身長、体重、体脂肪率、活動レベル、目標体重・目標体脂肪率、目標、レベル、利用可能器具、頻度、重点部位
  • ワークアウト記録: 種目名、重量、回数、セット数、日付
  • 通知・自動送信設定
  • AI会話の内容: AIトレーナーとのチャットメッセージ
  • 課金関連情報: Stripeから提供される顧客ID、サブスクリプションステータス、決済日時（カード番号は含まない）
  • 利用ログ: アクセス日時、利用機能、エラーログ

2. 利用目的

  1. 本サービスの提供および運営
  2. AIによるパーソナライズされたアドバイス・メニューの生成
  3. サブスクリプションの管理および課金処理
  4. 利用状況の分析および本サービスの改善
  5. お問い合わせへの対応・重要なお知らせの通知
  6. 不正利用の検知および防止

3. 第三者提供・業務委託先

当社は、本人の同意がある場合、法令に基づく場合を除き、個人情報を第三者に提供しません。ただし、本サービス提供のために以下の委託先に必要な情報を提供しています。各委託先はそれぞれのプライバシーポリシーに従って情報を取り扱います。

4. データの保管場所

個人情報は、Google Cloud Firestore（asia-northeast1 / 東京リージョン）に保管されます。

5. 個人情報の越境移転について

本サービスの提供にあたり、AIによる応答処理のため、利用者の個人情報の一部が以下の業務委託先を通じて日本国外で取り扱われる場合があります。利用者は、本サービスの利用にあたり、当該越境移転についてあらかじめ同意したものとみなします。

移転先所在国移転される情報
Anthropic, PBC アメリカ合衆国 AI応答生成に必要なメッセージ・ユーザープロフィール（カード情報を除く）
Stripe Inc. アメリカ合衆国 決済処理に必要な顧客情報・カード情報・取引情報

移転先の国における個人情報保護に関する制度および移転先が講ずる個人情報保護のための措置については、お問い合わせ窓口にご請求いただければ遅滞なく開示します。

6. 保管期間

  1. アクティブな利用者のデータは利用継続中保管されます。
  2. サブスクリプション解約後は、解約日から90日間保管した後に削除されます。
  3. 利用者が削除を申請した場合、原則として申請から30日以内に削除します。

7. 利用者の権利

利用者は、自己の個人情報について、開示・訂正・削除・利用停止・第三者提供停止を請求する権利を有します。請求は、お問い合わせ窓口へのご連絡により承ります。本人確認の上、遅滞なく対応します。

8. クッキー・LocalStorage

本サービスは、利用者の端末のLocalStorageに以下の情報を保存します。

  • オンボーディング完了状態
  • 操作チュートリアル（ツアー）の表示状態
  • LIFFのアクセストークン（LINE SDKによる管理）

9. AI処理に関する注意

AIトレーナーへのメッセージおよびトレーニング記録は、Anthropic, PBC のClaude APIを通じて処理されます。AnthropicはAPI経由のデータをモデル学習に使用しないことを明示しています（2026年5月時点）。詳細は Anthropicのプライバシーポリシー をご参照ください。

10. 安全管理措置

  1. 通信の暗号化（HTTPS / TLS）
  2. Firebase Security Rulesによるクライアント直接アクセス禁止
  3. LIFFアクセストークン認証によるユーザー識別
  4. 業務委託先の選定および監督
  5. カード情報を当社で保持しない設計（Stripeに完全委託）

11. プライバシーポリシーの変更

本ポリシーは必要に応じて変更することがあります。重要な変更は本サービス内またはLINEメッセージで通知します。
