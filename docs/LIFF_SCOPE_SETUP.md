# LIFF Scope セットアップ手順

> AI自動送信機能（D1）を有効にするために必要な設定手順。

## 背景

LIFF アプリから `liff.sendMessages()` API を使ってトークルームに自動でメッセージを送信するには、
LIFF アプリの **Scopes** に `chat_message.write` を追加する必要がある。

これがないと、ユーザーがプロフィール画面で「AI自動送信ON」にしてもAPI呼び出しが失敗し、
コードは graceful にフォールバック（closeWindow のみ）するが、ユーザー意図通りには動かない。

---

## 設定手順

1. https://developers.line.biz/console/ にログイン
2. 該当の **Provider** → **LINE Login Channel** を開く
   - LIFFアプリは LINE Login channel に紐づく
3. 上部タブから **「LIFF」** を開く
4. 該当の LIFF アプリ（`2009308929-2EtqmAKD` の `2EtqmAKD` 部分）の行をクリック
5. **Scopes** セクションで以下にチェックを入れる:
   - ✅ `profile`（既にONのはず）
   - ✅ `openid`（既にONのはず）
   - ✅ **`chat_message.write`** ← これを追加
6. ページ下部の **「Update」** ボタンを押して保存
7. 反映には数分かかる場合あり

---

## 確認方法

スコープ追加後、本番でD2-5のテストを実施：

1. LIFF アプリのプロフィール画面 → 通知 / その他 セクション
2. 「AI自動送信」を ON、メッセージは「今日の記録を分析して」のまま保存
3. 記録画面で何か1セット入力して保存
4. 保存成功後の「**AIコーチに今日の記録を分析してもらう →**」CTAをタップ
5. LIFFが閉じてLINEトークに戻る
6. **トーク画面に "今日の記録を分析して" が自分の発言として送信されている**
7. AIから応答が返ってくる

スコープ未付与の場合: 6 のメッセージ送信が失敗し、ブラウザコンソールに警告が出る。
LIFFは普通に閉じるので、ユーザーは違和感ないが自動送信は動作しない。

---

## ユーザー側の同意

スコープを追加すると、新規ユーザーが LIFF を初めて開く時に LINE が **「このアプリにメッセージ送信を許可しますか？」**
の同意画面を表示する。これは LINE プラットフォーム側の標準動作で、こちら側では制御不可。

既にLIFFを利用しているユーザーは、再度同意画面が出るので「許可」を押してもらう必要がある。

---

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| `liff.sendMessages` が `code: 403` で失敗 | スコープ未付与 or ユーザーが許可していない | コンソールでScope確認 + ユーザーに同意を促す |
| 反映されない | LINE側のキャッシュ | 5〜10分待つ。LIFFアプリを開き直す |
| AndroidのLINEだけ動かない | LINE バージョン古い | LINE 11.16.0 以上必要。アップデート案内 |
